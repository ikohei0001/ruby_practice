このリポジトリには、プログラミング学習目的でAIに作成してもらった問題に対する私の解答コードをまとめています。

## Overview
This repository contains my solution code to problems generated by AI for learning programming.

- Ruby : 3.1.2p20 (2022-04-12 revision 4491bb740a) [aarch64-linux]
- AI : ChatGPT ( GPT-5.2 / Free plan )

## 内容
### 問題1 : 数字を入力して３倍にする
標準入力から受け取った整数を３倍にして出力する。<br>
<br>
※問題1は学習初期に作成したシンプルな実装例です。3問目以降では、MinitestやRSpecを用いたテストコードも追加しています。

### 問題2 : 配列の合計を出すメソッドを定義する
標準入力から整数をスペース区切りで受け取り、それを配列に変換する。<br>
各要素が整数値の配列を引数として受け取り、その合計値を返すsum_arrayメソッドを定義せよ。<br>
また、定義したメソッドに対して簡単なテストを定義せよ。

### 問題3 : 配列から偶数を順序通りに抽出するメソッドを定義する
標準入力から整数をスペース区切りで受け取り、それを配列に変換する。<br>
各要素が整数値の配列を引数として受け取り、その中から偶数のみ順番を保ったまま返すメソッドを定義せよ。<br>
出力はスペース区切りで行うこと。<br>
さらに、定義したメソッドに対して標準ライブラリのテストフレームワークを用いてテストを作成せよ。

### 問題4 : 文字列を逆にするメソッドを定義する
文字列を引数として受け取り、文字単位で逆順にした文字列を返すメソッドを定義せよ。<br>
さらに、定義したメソッドに対してRSpecテストフレームワークを用いてテストを作成せよ。<br>

例：<br>
入力: hello<br>
出力: olleh

### 問題5 : Personクラスを作成する
nameとageの属性を持つ。<br>
greetingメソッドを定義し、文字列"Hello, my name is NAME and I'm AGE years old."を返す。※NAME, AGEはインスタンスの値に置き換える。<br>
age_next_yearメソッドを定義し、次の年齢を返す。<br>
さらに、作成したクラスの振る舞いをRSpecでテストすること。

### 問題6 : 整数の約数を昇順で返すメソッドを作成する
1以上の整数nが与えられた時、その整数の全ての約数を小さい順に並べた配列を返すメソッドを作成してください。<br>

条件 :<br>
・入力は常に1以上の整数<br>
・出力は配列で昇順に並んでいること<br>

例：<br>
・入力 : 12<br>
・出力 : [1, 2, 3, 4, 6, 12]

### 問題7 : BMIを計算し判定を返すメソッド群を定義する
次の2つのメソッドを作成してください。<br>
体重(kg)と身長(cm)を引数として受け取り、 BMI値を計算して小数点以下2桁で返すメソッド<br>
BMI値を引数として受け取り、 日本肥満学会の判定基準に基づく分類名(文字列)を返すメソッド

### 問題8 : 統計値を返すメソッドを定義する
数値のみを要素にもつ配列を引数に取り、平均値・母標準偏差・中央値・最頻値を計算して返すメソッドを作成してください。<br>

条件 :<br>
・返り値はHashとする<br>
・配列が空、または数値以外を含む場合はArgumentErrorを発生させる

### 問題9 : 英単語をソートするメソッドを定義する
英単語(簡単のためa〜z, A〜Zのみからなる文字列)の配列を与えると，辞書順に並べ替えた配列を返すメソッドを作成してください。<br>

条件<br>
・大文字／小文字は無視して配列するが，同順の場合は小文字を前にする
