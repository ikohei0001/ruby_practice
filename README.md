## 内容
### 問題1 : 数字を入力して３倍にする
標準入力から受け取った整数を３倍にして出力する。<br>
<br>
※問題1は学習初期に作成したシンプルな実装例です。3問目以降では、MinitestやRSpecを用いたテストコードも追加しています。

### 問題2 : 配列の合計を出すメソッドを定義する
標準入力から整数をスペース区切りで受け取り、それを配列に変換する。
各要素が整数値の配列を引数として受け取り、その合計値を返すsum_arrayメソッドを定義せよ。
また、定義したメソッドに対して簡単なテストを定義せよ。

### 問題3 : 配列から偶数を順序通りに抽出するメソッドを定義する
標準入力から整数をスペース区切りで受け取り、それを配列に変換する。
各要素が整数値の配列を引数として受け取り、その中から偶数のみ順番を保ったまま返すメソッドを定義せよ。
出力はスペース区切りで行うこと。
さらに、定義したメソッドに対して標準ライブラリのテストフレームワークを用いてテストを作成せよ。

### 問題7 : BMIを計算し判定を返すメソッド群を定義する
次の2つのメソッドを作成してください。
体重(kg)と身長(cm)を引数として受け取り、 BMI値を計算して小数点以下2桁で返すメソッド
BMI値を引数として受け取り、 日本肥満学会の判定基準に基づく分類名(文字列)を返すメソッド
