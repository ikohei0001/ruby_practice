## 内容
### 問題1 : 数字を入力して３倍にする
標準入力から受け取った整数を３倍にして出力する。<br>
<br>
※問題1は学習初期に作成したシンプルな実装例です。3問目以降では、MinitestやRSpecを用いたテストコードも追加しています。

### 問題2 : 配列の合計を出すメソッドを定義する
標準入力から整数をスペース区切りで受け取り、それを配列に変換する。
各要素が整数値の配列を引数として受け取り、その合計値を返すsum_arrayメソッドを定義せよ。
また、定義したメソッドに対して簡単なテストを定義せよ。
